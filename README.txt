Dance Pilates Steps Sleep

1. Put this folder on any static HTTPS host (for example GitHub Pages, Netlify or Cloudflare Pages).
2. Open the site in Safari on your iPhone, tap Share, then Add to Home Screen.
3. From then on, open it from the Home Screen icon.

Your marks are saved on the phone only, inside the Home Screen app. There is no account and no server.
iOS keeps the Home Screen app's data separate from Safari's, and deleting the icon deletes the marks.
